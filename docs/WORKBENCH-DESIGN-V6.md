# 配方工作台 v6：识别物与画布同屏

- 日期：2026-11-27；基于 v5（四栏布局、顶部板块 Tab、弹窗维护已成型）。
- 来源：用户反馈——识别物要和中间截图同时展示，方便一眼查找定位。
- 约束不变：纯 HTML/原生 JS、双击可开、零网络、不碰 `src/`；v5 数据平滑迁移。
- 注：结构化步骤模型的 A/B/C 取舍用户尚未拍板，本版**不删 steps**，只调整识别物展示方式。

## 一、核心改动：识别物清单贴画布展示

### 1.1 画布区内置识别物侧条
- 在中央画布列内部右侧（或左侧，做成可换边）增加「本帧识别物」清单，与截图同屏，不占用右栏 Tab。
- 清单只显示**当前帧**元素：中文名 + 类型小色标（取点/区域/参考图/文字识别）+ 坐标摘要。
- 与画布标注双向联动：
  - 点清单项 → 画布对应标注高亮（描边加粗+闪烁一次），必要时自动缩放适配到该元素
  - 点画布标注 → 清单对应项滚动到可视区并高亮
- 悬停清单项显示浮层：完整坐标、阈值/期望文字、来源帧；点击「编辑」仍可打开现有 popover。
- 清单支持搜索/过滤（按中文名、类型），帧上元素多时用得上。

### 1.2 空态与密度
- 当前帧无识别物：清单区显示引导「在画面上取点/框选即可生成识别物」。
- 清单可折叠成窄条（只显色点），给画布让空间；折叠状态记忆到 localStorage。
- 清单宽度固定建议 200–240px，画布剩余空间仍保留缩放平移能力。

## 二、右栏调整

- 右栏三 Tab（流程/识别物/设置）中的「识别物」改为**跨帧全量库**：显示当前场景所有帧的识别物（带帧序号），用于跨帧查找和统一管理；画布侧条负责当前帧的快速定位，两者定位不同、都保留。
- 「流程」Tab 维持现状（步骤模型待 A/B/C 决策后再改）。

## 二点五、步骤模型定调（用户拍板 A 方案）

- 决策：steps 数据结构保留（执行引擎/AI 生成/测试断言的期权），但**从用户日常界面退场**。
- 「流程」Tab 上半部仍是流程说明（大白话，用户主维护区）；结构化步骤编辑区默认折叠，标题「高级：手动编辑步骤（通常不用管）」，展开后才显示现有步骤卡片。
- 面向用户的文案不再引导手摆步骤；README 明确用户主路径=写说明+管截图+标识别物，步骤由后续 AI/引擎根据说明与标注生成。
- 交接包保留步骤 JSON，但固定放在文末「机器配置」区。

## 三、其他要求

- 画布 popover、缩放平移、标注四色、中文命名校验、引用完整性、交接包、快照全部保留。
- check 脚本补：双向联动（模拟选中元素后画布高亮状态）、清单只含当前帧元素、折叠态持久化。
- README 更新布局说明；浏览器点测项（闪烁、自动缩放、搜索过滤、折叠）如实列出。
- 不新增真机对接、真实 OCR 或模板裁剪。
