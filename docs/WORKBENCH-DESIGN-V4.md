# 配方工作台 v4：布局重构与信息层级

- 日期：2026-11-27；基于 v3（功能已齐，用户反馈视觉乱、五列拥挤）。
- 目标：从「功能堆叠」改成「画布优先」的工作台，默认界面安静，需要时才展开细节。
- 约束不变：纯 HTML/原生 JS、双击可开、零网络、不碰 `src/`；v3 数据平滑迁移。

## 一、现存问题（用户截图确认）

1. 五列等宽竖排全摊开（导航/帧序列/画布/编辑/设置），主画布被挤压，视觉无主次。
2. 步骤卡片默认展开全部字段，一个步骤占大半屏，流程长了无法纵览。
3. 工具栏出现两个「100%」（按钮与比例指示重复）。
4. 迁移场景步骤报「引用缺失：tpl_energy_icon」——需排查 v2→v3 迁移后步骤与元素的引用完整性，是 bug 不是提示。
5. 右侧「场景设置」内部 ID 等机器字段和常用操作混放，高级项没有真正藏起来。
6. 帧序列、识别物列表缺少折叠，信息密度过高。

## 二、新布局：三区 + 抽屉

### 2.1 顶栏（固定，高度一行）
- 左：面包屑（板块/场景/当前帧）+ 场景频率标签
- 中：模拟运行按钮（主按钮样式）
- 右：导入导出、交接包、快照，收进「更多」菜单，只留图标+文字两个常用项

### 2.2 左栏（可折叠，默认 240px，两个折叠区）
- 「场景」区：板块分组+场景列表（精简为单行：名称+频率小标签，操作按钮 hover 才出现）
- 「截图序列」区：缩略图卡片，当前场景名固定在区标题；支持折叠成窄条只显缩略图
- 左栏整体可一键收起为 48px 图标条，给画布让空间

### 2.3 中央画布区（占最大面积，主角）
- 画布工具条精简为一行：[取点|区域|参考图|文字] 分段控件 + [适应|100%|复位] + 缩放比例文字（删掉重复的 100% 按钮）
- 画布下方保留坐标读数和操作提示，字号收小
- 当前帧识别物改成「浮层清单」：默认只在画布上显示彩色标注，点击标注才弹出该元素的编辑小卡（popover），不再常驻右侧长列表

### 2.4 右栏（标签页切换，不再纵向堆叠）
三个 Tab，一次只看一个：
1. **流程**：大白话说明文本框（上）+ 步骤/分支时间线（下）。步骤卡片默认折叠成一行：`序号 · 类型中文 · 一句话note · 档位标 · 状态点`；点击才展开字段编辑；引用缺失用红色徽章醒目提示并支持点击定位
2. **识别物**：当前帧元素的表格化清单（中文名、类型、来源帧、坐标摘要），点击在画布高亮
3. **设置**：场景名、频率、入口、失败策略等；内部 ID、机器 JSON 放最下面「高级（折叠）」

## 三、交互与视觉规范

- 配色：深色底 + 一个主色（沿用当前金/青之一即可），类型四色只用于标注与小徽章，不大面积铺色
- 间距统一 8px 栅格；卡片圆角、边框、hover 态统一
- 所有破坏性操作（删除场景/帧/分支、快照恢复）走统一确认弹窗
- 空状态给引导文案（如「先在左侧导入截图」「点击画布开始标注」）
- 中文字号分层：标题 16、分区 14、正文 13、辅助 12，避免现在的大小混乱

## 四、必须修复的 bug

1. **引用完整性**：排查 v2/v3 迁移后步骤引用元素显示「引用缺失」的原因（元素 frameId、ref 变更、下拉过滤条件），写 check 用例：迁移后的场景步骤若元素存在不得报缺失；确实缺失的给出修复入口（重选/删除步骤）。
2. check-v3 补齐：分支删除、OCR 元素结构、迁移引用完整性三组断言。
3. 缩放控件重复 100% 问题。

## 五、验收与回报

- `node --check workbench/app.js`、扩展后的 check 脚本全过；README 更新布局说明。
- 四件套回报，重点说明新布局的折叠/标签切换、引用 bug 根因与修法；浏览器点测项（缩放、拖拽、弹窗、popover）如实列出。
- 不新增功能需求，本轮只做布局重构、视觉整理和 bug 修复；v3 已有数据与操作习惯尽量保持。
