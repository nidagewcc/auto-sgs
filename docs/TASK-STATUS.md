# 任务进度与执行记录

开发与验证：**Codex**，2026-11-26。

## 手机怎么看

- **运行时**：底部中央持续显示当前任务、步骤、说明与耗时。悬浮球变为橙色「停」，点击会请求停止；球仍可拖动。
- **收尾时**：状态显示「收尾中」，任务互斥保持到截图/日志处理结束，不提前显示最终完成。
- **结束后**：状态条持续保留本次结果与原因，直到下次任务更新；成功为绿色，待确认为黄色，失败为红色，跳过/停止为灰色。
- **查看明细**：任务空闲时长按悬浮球，选择「执行状态与最近记录」。可查看最近 20 次执行的开始时间、耗时、结果和原因；日常任务会逐项显示成功、失败、待确认、跳过或未执行。

运行中不展开大面板，避免遮住游戏 OCR 或按钮；大面板入口会提示查看底部状态并使用「停」。底部状态条设置 `FLAG_NOT_TOUCHABLE`，窗口透明度为 0.7，低于 Android 12+ 默认的 0.8 遮挡阈值，避免系统把其下的游戏触摸判为不可信；不挡住奖励空白关闭等操作。

## 结果是什么意思

| 显示 | 含义 |
| --- | --- |
| 运行中 | 工作线程仍在检查页面或执行任务，步骤随关键阶段更新 |
| 收尾中 | 业务操作已返回，正在处理结果及回传 |
| 正在停止 | 已请求中断，尚未确认线程退出；迟到的进度不能覆盖这个状态 |
| 成功 | 任务返回完成证据，且必要的主城复检通过 |
| 已跳过 | 本次没有需要执行的内容或明确无可用入口 |
| 待确认 | 执行过操作，但缺少足够完成证据；不计入成功 |
| 失败 | 异常、页面未确认或回传明确失败，记录保留具体原因 |
| 已停止 | 用户请求停止后，当前工作线程已结束 |

记录中的耗时包含前置检查、任务执行和收尾；终态耗时冻结，不随空闲时间继续增长。

副本明细会说明本轮扫荡次数、是否花 20 元宝重置，以及战报/收益确认状态。例如「已扫荡 5 次，已重置 20 元宝，已见战报但收益未确认」，避免把「操作发生了」和「收益已验证」混成同一结论。

截图回传也检查真实返回值：未配置电脑端、无截图、网络异常或 HTTP 非成功状态均不会显示「截图已上传」。

## 各流程的关键步骤

- 邮件：打开邮件 → 领取及核对奖励/空状态 → 返回主城 → 复检。
- 小乔：打开助手 → 等待整套完成（显示剩余等待上限）→ 核对结果/返回主城 → 复检。
- 军情：打开入口 → 挑战及击杀确认 → 返回主城 → 复检。
- 副本：进入 BOSS 面板 → 读取次数/准备扫荡 → 等待战报 → 返回主城 → 复检。
- 玩家信息：采集画面 → 逐一核对七个字段 → 主城复检。
- 一键日常：显示当前第几项、任务名及该任务内部步骤，最后保留整轮逐项结果。

本功能沿用手动登录约定，不自动启动游戏、登录或切号；不会因「待确认」自动重跑消费任务。最终状态仍依赖现有模板、OCR 与完成标志，记录不会把不足的证据变成成功。

## 保存与窗口生命周期

状态保存在固定 `/sdcard/Download/autosgs-logs/task-status.json`，只写该文件及同名 `.tmp`，规范路径检查后同目录重命名保存。最多保留 20 条记录；这里的截断仅更新 JSON 列表，不删除照片、日志或其他文件。

- 任务令牌隔离新旧任务，旧任务不能改写新任务状态。
- 状态操作和持久化使用同一可重入锁，停止与工作线程进度不能交叉覆盖，也避免共享临时文件写入竞争。
- 重启时发现上次没有结束记录，会显示「待确认：上次运行没有结束记录」，不会推断成功或自动恢复执行。
- 状态条与结果窗口分别使用 `auto-sgs:status`、`auto-sgs:results` 标签，加入既有窗口登记、退出清理和遗留回收；单独的刷新定时器不依赖主面板展开，退出时停止。
- 存储错误不会掩盖业务结果；本轮内存显示仍保留，日志会提示保存失败。

调试控制 `status:show` / `status:hide` 仅打开或关闭记录面板，不执行任何游戏任务。运行中拒绝打开大面板。

## 验证

新增状态模型、状态窗口、任务入口集成及真实回传返回值测试；与既有日常、恢复、停止、截图管理和归档安全回归一起，13 组测试全部通过。明确计数的测试合计 182 项，另有日常设置和状态窗口交互检查。构建、bundle 语法及差异检查通过。

真机只运行一次只读玩家信息日常：确认运行阶段可见、约 12 秒后保留成功结果与七字段说明；记录窗口可以打开/关闭；日常默认方案保持不变。最终是一个悬浮球和一条独立的不可触摸状态条，没有重复悬浮球，也没有运行领取、挑战、扫荡或切号。

运行中、结束后和记录面板的截图及 JSON 验证资料保留在本机 `_shot/`，不入 Git。
