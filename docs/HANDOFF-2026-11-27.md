## 4. 手机端关键事实（避免重踩坑）

- adb：`D:\develops\tools\platform-tools\adb.exe`；设备 M332BF，mDNS 名 `adb-52059658-wzxgd4._adb-tls-connect._tcp`；192.168.3.16 未授权禁止碰。
- **换电脑后 adb RSA 密钥不同，无线调试要重新配对一次**（手机上看配对码），配对一次后后续 mDNS 自动重连。
- `adb input tap` 在 Cocos 层被吞；脚本内无障碍 `click()` 有效，远程点击走 autotask 的 `tap:x,y`；`adb shell input swipe` 有效（1200px/300–350ms）。
- 禁止跨面板复用历史坐标，点击四步走：检测定位→裁剪确认→tap→帧差验证，无变化即停报。
- 部署后在游戏前台热重载（reload）曾多次申请截图权限失败；若失败，可将 AutoJs6 切前台手动运行并允许「共享屏幕」，不能断言游戏前台必然失败。
- 任务投递：写 `/sdcard/Download/autosgs-logs/autotask.txt`（如 `echo -n daily`），3 秒心跳轮询。
- 日志：结构化日志在 logcat（GlobalConsole 标签），业务日志在 run.log。
