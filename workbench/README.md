# 场景工作台 v6（离线原型）

主路径是写流程说明、管理截图并标注识别物；手动步骤编辑默认折叠在流程页的「高级」中，步骤数据仍保留，后续 AI 或引擎生成尚未实现。画布旁的本帧清单支持搜索、类型过滤、切换左右与折叠，偏好保存在本地；选择条目可定位标注，画布选择标注可定位清单，编辑沿用浮层。右栏识别物为跨帧全库。浏览器实际交互（闪烁、缩放、过滤、折叠和联动）仍需点测。

顶部标签切换日常任务、敦煌密窟和特殊活动，面包屑显示场景和帧，右侧「更多」提供导入导出、交接和快照；左侧可收起，场景与截图序列可分别折叠。右栏「流程」「识别物」「设置」按标签切换，步骤点击标题展开或收起；点击画布标注或识别物列表可打开编辑浮层。侧栏收起后保留 48px 缩略图条，点击缩略图切换帧；再点顶部按钮展开。若原有浏览器数据仍显示引用缺失，展开对应步骤后可重新选择识别物或删除步骤；目前尚未确认用户原有提示的具体根因。机器配置和内部 ID 在设置的高级折叠区。

双击 `index.html`，无需服务器、网络、构建工具或手机。场景是一个完整的活儿；说明、步骤、识别物和分支共同描述这个活儿。页面只模拟，不会操作手机，也不执行 A/B 安全规则。

选择板块并新建场景，填写执行频率，在「流程说明（大白话）」写下意图。右侧「操作流程」编辑默认流程或分支；分支条件仅记录识别物，模拟时需手动选择分支，不会自动识别。每个步骤可填写「这一步在干嘛」。灰色的「生成步骤」尚未对接，不能自动生成。

为场景批量导入截图，逐帧取点、框选区域或参考图，识别物需填写中文名称。文字识别物设置区域和期望文字，等待文字步骤可引用它。内部英文 ref 是自动生成的稳定机器标识，不是中文语义翻译；重命名中文名称不会改变引用。旧数据没有中文名时显示旧 ref 并提示补充。模板裁剪和 OCR 仍是占位，不生成真实模板或执行识别。

画布滚轮以鼠标为中心缩放，按空格或中键拖动，提供适应窗口、100% 和复位；标注始终使用 2772×1280 逻辑坐标。图片长宽比例不同时会拉伸。导入图片及快照占浏览器本地存储，容量受限，请及时导出备份。

JSON 导入导出和快照保留场景说明、分支、步骤备注和图片；交接包按场景信息、说明、帧清单、流程、识别物、机器数据排列。删除场景或截图、恢复快照需要确认；删除识别物可能导致步骤引用失效，需手工修复。

首次打开自动从 v2 本地存储迁移到 v3，保留 v2 原数据；没有 v2 时尝试迁移 v1，否则使用示例。v3 中场景新增 `schedule`、`branches`、`description`，步骤新增 `note`，识别物新增 `label`；原引用 ref 保留。不同浏览器或 file 来源的存储可能互不共享。

后续真机对接需另定截图流、坐标与分辨率、真实模板和 OCR、点击滑动、调度与日志、资源同步及安全确认接口。本版本没有这些接口。

本地检查：`node --check workbench/app.js`、`node workbench/check-v3.js`。模拟 DOM 检查不代替浏览器操作验收。

顶部切换板块后，侧栏只显示当前板块的场景。点击「新建场景」或场景右侧「⋯」中的编辑，在统一弹窗中修改中文名称、所属板块、执行频率、排序权重、入口和失败策略。权重越小越靠前，相同权重保持原顺序；复制需确认名称，删除会提示连带删除场景数据。截图仍可拖动排序。旧场景按原数组顺序自动补充 10、20、30 等权重。

截图序列位于场景列表右侧的独立列，点击「收起截图」可缩成48px缩略条并切帧，场景栏可单独收起。截图的「⋯」菜单可编辑名称、备注和排序权重，或复制、删除、上下移；拖拽仍可排序。删除截图会删除其识别物，引用这些识别物的步骤保留并提示引用缺失。
